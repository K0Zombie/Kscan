# Kscan 使用说明

完整解压后运行 kscan-gui.exe。录制需另行配置 FFmpeg。便携数据位于 data；切换版本前先退出托盘中的旧实例。

双击 [完整离线帮助](帮助文档/index.html) 阅读浏览器版手册，或打开帮助文档目录中的 Markdown。软件内“设置 → 命名与标注 → 打开使用手册”指向同一份帮助。

常用键：F1 截图复制、Ctrl+F1 截图扫码、F3 贴剪贴板、Ctrl+F3 截图贴图、Ctrl+Shift+F2 滚动截图。已有配置的按键可能不同，以设置页为准。

本包为录制功能分支，未合并 main。新功能及限制请查看完整手册中的版本说明。旧包可保留回退；不要覆盖或分发个人 data 和录制文件。

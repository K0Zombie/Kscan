Kscan 使用手册

设置、主题与字体

窗口背景材质

在“设置 → 外观 → 窗口背景材质”选择纯色、Mica 或 Acrylic，即时应用到主窗口和独立标注编辑器。Mica 使用桌面壁纸色调（Windows 11），Acrylic 模糊窗口后方内容（Windows 10 1803 及以上）。系统无法提供效果时回退主题纯色；贴图和截图遮罩保留各自的透明方式。

设置按用途分为通用、录制、文件命名、外观、热键、执行命令、识别、贴图、多屏、标注、界面和权限。支持情况取决于平台；开机启动、托盘、捕获排除等以平台能力提示为准。

外观

可选深色、浅色、跟随系统，以及自定义主题。调整颜色、字体、圆角等预览后，保存当前主题或另存为主题，才能长期保留。用户主题 JSON 位于便携 data/user/themes/，外部修改会触发重新加载。

主题的 fontFamily 是界面字体。留空沿用已解析的默认字体；不要手工填写 $Default。更换不存在的字体可能造成显示异常，优先使用系统已安装字体。字号和标注颜色不是界面主题颜色的一部分。

录制框选提示、选区边框、控制窗、计时跟随主题动态变化。选区用强调色，正在录制的边框用主题警示色。提示和计时使用主题底色保证文字可读。贴图管理窗口也同步主题，但分组标识色仍按各组设置保留。

mask.style 的 dim 表示按 mask.color 压暗；none 不铺遮罩。主题调整不改变已经捕获的图片像素，也不会把录制水印自动重染成主题文字色。水印颜色在标注里单独设置，字体跟随主题。

保存位置与生效

一般设置更改后会保存；录制、文件命名、画面标注及 JSON 编辑器中有明确保存按钮，修改后需点击保存。JSON “应用到编辑器”不等于已经持久化。保存失败会显示状态，检查目录写权限与磁盘空间。

自定义主题保存在 user 目录；程序内设置保存在 settings.json。替换程序文件不应删除这些用户数据。当前已开始的录制沿用启动时的命名和画面文字设置，后续新会话使用新设置。

帮助与界面语言

界面语言可选择中文、英文或跟随系统。本轮新增命名规则说明与手册以中文为主，变量名称固定英文，便于 JSON 和程序员接口统一。

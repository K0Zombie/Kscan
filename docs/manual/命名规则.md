# 文件命名模板与高级规则

在设置 → 命名与标注选择类型，编辑模板，观察示例并保存。变量使用英文，说明使用中文。变量按钮插入到光标位置。示例使用样本宽高和计数，不会创建文件或消耗实际序号。

支持 screenshot、scroll、annotation、pin、barcode、clipboard、video、gif、audio。screenshot 对应普通截图，scroll 对应长图，annotation 对应标注结果；pin 是贴图另存，barcode 是生成结果，clipboard 是保存剪贴板文本。普通截图及标注的复制操作也会为文件项使用这些模板。

## 基础变量

| 变量 | 含义 | 示例 |
| --- | --- | --- |
| `{type}` | 当前输出类型 | video |
| `{date:yyyyMMdd}` | 本地日期，可指定 .NET 日期格式 | 20261028 |
| `{time:HHmmss}` | 本地时间，HH 是 24 小时制 | 113025 |
| `{datetime:yyyy-MM-dd_HH-mm-ss}` | 日期和时间 | 2026-10-28_11-30-25 |
| `{counter:000}` | 当前进程内共享计数，可补零 | 007 |
| `{width}` / `{height}` | 输出画面像素尺寸，未知或音频为 0 | 1920 / 1080 |
| `{title}` | 来源名称或可获得的前台窗口标题，可能为空 | Example window |
| `{ext}` | 扩展名文字，不带点 | mp4 |

默认模板：`{type}_{date:yyyyMMdd}_{time:HHmmssfff}_{counter:000}`。文件扩展名由输出格式自动追加，通常不必在模板中再写 `{ext}`。格式错误会在预览或保存时提示。

计数在不同类型间共享，重启程序从头计数；并非按文件夹持久化的业务流水号。已有同名输出或正在编码的同名 .partial 文件会避让，追加 -1、-2 等。保存对话框里的建议名称仍允许用户修改；手动选择覆盖已有文件时按系统对话框处理。

## 处理与条件

```text
{title|default:untitled|trim|slug|truncate:40}_{date:yyyy-MM-dd}
{if:type=gif?animation:recording}_{counter:000}
```

管道按从左到右依次处理。支持 lower、upper、trim、slug、default:文字、truncate:长度。slug 保留字母、数字、下划线、横线，把其他连续符号压成横线；中文属于字母，可以保留。truncate 长度范围为 1–200。

条件写法为 `{if:变量=值?匹配时文字:否则文字}`，比较忽略大小写；分支是普通文字，不支持嵌套表达式。`{{` 和 `}}` 分别表示文字花括号。单个表达式不能嵌套，模板最长 2048 字符。

非法文件名字符、目录分隔符和控制字符被替换，下尾句点、空格会去掉；Windows 保留名如 CON 自动加前缀，空名称变为 untitled。输出长度上限 180 字符。模板不能通过目录分隔符把文件写到其他目录。

## JSON 规则

高级区可把当前编辑器内容生成 JSON；复制或粘贴后点击“应用到编辑器”，检查预览，再点保存。这里只放命名对象，不是整个 settings.json：

```json
{
  "templates": {
    "video": "{type}_{date:yyyyMMdd}_{time:HHmmss}_{counter:000}",
    "gif": "{if:type=gif?animation:recording}_{title|default:untitled|slug}_{counter:000}"
  },
  "stampTemplate": "{date:yyyy-MM-dd} {time:HH:mm:ss}",
  "recordStamp": false,
  "liveStamp": true,
  "stampPosition": "bottom-right",
  "stampSize": 20,
  "stampColor": "#FFFFFFFF",
  "stampOpacity": 0.9
}
```

未写入的输出类型使用默认文件模板。保存目录在截图/录制原有设置中选择，不写在模板里。已开始录制的文件名不会随实时水印时钟变化。

## 时间标注与程序员扩展

画面文字使用 stampTemplate，保留冒号等普通文本字符，不执行文件名清理。录制可选固定开始时间或实时更新；日期时间按系统本地时间生成。字号 8–96，透明度 0.1–1，位置可选 top-left、top-right、bottom-left、bottom-right，字体跟随主题。颜色可写 #AARRGGBB。

程序员可以引用 Core 的 `NameTemplate.Render(template, context, resolveToken: ...)`，注入自定义变量解析器；GUI 的公开 `FileNaming.RegisterToken("custom_project", context => "ProjectA")` 可在宿主启动阶段注册扩展变量。扩展名称须以 custom_ 开头。

这是代码集成接口，当前没有“把 DLL 放目录就自动加载”的插件管理器，也不从用户 JSON 执行 JavaScript、PowerShell、C# 或系统命令。GUI 的普通规则校验只接受内置变量；自行集成的宿主可使用 Core 接口对自定义规则作相同校验。JSON 字段和模板语法可直接供外部工具生成。

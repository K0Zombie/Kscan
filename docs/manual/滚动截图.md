# 滚动截图

## 完整操作

1. 按 Ctrl+Shift+F2，框选同一屏幕内真正会滚动的内容区。
2. 将鼠标放回选区内，手动向下或向上滚动。顶部新增内容接在长图前，底部新增内容接在长图后。
3. 查看选区旁的实时预览。暂停时可以检查页面，再继续采集。
4. 完成时点“完成并调整起止”，按行精细裁切开头、结尾。
5. 进入标注编辑器；长图默认按 100% 从顶部查看。完成后复制，不会为了适应屏幕而压缩原图。

选区以外变暗并显示边框，工具栏与预览不会被遮罩盖住。Esc 或取消按钮退出；暂停和等待拼接时也可退出。退出后清除遮罩并停止采集。

## 快速滚动与重复区域

采集目标间隔为 40ms，后台按顺序拼接，队列有界。队列忙时临时缓采，腾出后继续，不会因为缓存满永久暂停。

上下往返到已采集范围时只更新位置，不重复加图。“撤销上一段”按新增时间顺序撤销，既能撤销顶部段也能撤销底部段。主动暂停会保持暂停提示，不会被排队帧覆盖。

拼接仍需要重叠内容，通常至少 32 行或选区高度的 5%，取较大者。一下跳过整屏、页面还未绘制好或内容被虚拟列表替换时，软件无法补出从未捕获的部分。此时回滚到上一段附近，减慢滚动重新接续。

## 预览与裁切

实时大预览优先放在框选旁的空白位置，优先左右侧，再尝试上下方或其他屏幕。空间不足时保留工具栏小预览。预览刷新不会复制整张长图。

点击预览或放大预览会暂停采集，以原始像素查看，支持缩放、滚动、适应宽度。关闭后恢复之前的状态。按一次 Esc 先关闭放大预览；松开后再次按 Esc 才取消整个采集。

起止裁切按原始行号处理；界面主题跟随软件。进入标注后还可继续裁剪，导出只取裁剪范围。

## 上限与排查

默认上限为 100000 行和 1.28 亿像素，先达到哪个就停止扩展；宽度越大，可用行数越少。工具栏会显示当前宽度对应的限制。位图、预览、历史与编解码还会额外使用内存，不能把像素上限当作总内存上限。

滚动后未接上时先看：是否主动暂停、是否接近像素限制、是否选进固定工具栏、是否完全没有重叠、页面是否在异步加载。不要把固定顶栏和悬浮广告包含在采集区域里；它们会干扰匹配。

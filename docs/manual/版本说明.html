Kscan 使用手册

版本与支持范围

本手册对应 Kscan 0.1.16 的 feature/region-recording 分支，不代表 main 已合并该分支。

已包含

  • main 的普通命令权限处理、贴图放大裁切修复，以及截图、扫码、条码生成、多屏、双向滚动截图和标注。
  • 独立录制设置页：GIF、MP4、M4A，系统声音、麦克风与混合音源；实时不激活框选，指针尺寸修正，首帧就绪检测。
  • GIF 保存自动复制，F3 读取文件项并播放 GIF/动画 WebP。
  • 录制提示、边框和计时跟随主题；提示文字不再使用导致闪退的未解析默认字体。
  • 英文命名模板、预览、格式化、条件与字符串处理，JSON 导入编辑器和导出。
  • 截图编辑器可插入时间文字，录制可启用固定或实时画面时间标注。
  • 本地 Markdown 和 HTML 帮助随便携包交付。

边界

录制使用 Windows gdigrab 目标帧率，尚未实现显示器逐刷新事件同步；FFmpeg 单独配置，包内不捆绑。录制画面标注是实际桌面图层，重叠录制可能同时捕获到它。

高级编码参数是受限选项入口，不是任意 FFmpeg 命令行。命名扩展是代码集成接口，没有自动 DLL 加载器或任意脚本执行。counter 仅当前进程内计数，不是持久业务编号。

动画贴图仍有帧数、尺寸和总内存上限；APNG 多帧支持受解码器限制。滚动拼接需要画面重叠；跨屏录制、高刷新率、多会话、独占全屏、受保护内容、长时混合音频须结合实际硬件验证。

微信或其他扫码登录协议不因识别二维码而被绕过；电脑已登录微信不代表任意应用都允许免手机确认。

开发者构建与备份

需要 .NET 10 SDK，源码内分别有 CLI、GUI 和测试项目。常见 Windows GUI 发布方式：


dotnet publish GUI/Kscan.App.csproj -c Release -r win-x64 --self-contained true

extract/pack.ps1 从源码发布完整便携版、源码 ZIP 及 SHA-256，并保留已有产物；功能分支包名含分支标识。使用打包脚本前会生成离线帮助，正常项目 publish 也会携带已生成的帮助文件。

用户数据不应纳入分发包。测试报告按实际完成项目写，不把合成素材编码或单屏验证当成所有设备均满帧的保证。内部设计与验证说明分别保留在 docs/DESIGN.md、PIN-SIZING-CHECK.md，不作为用户操作手册。

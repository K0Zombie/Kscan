# 快捷键与自定义命令

## 录制和注册结果

点击“录制”，按下所需组合键，再确认保存。支持普通键、小键盘、常见符号键、多媒体键及 F1–F24。只能录制 Windows 实际上报的按键；由固件处理的 Fn 无法单独识别，可使用键盘软件映射后的按键。系统保留组合可能无法注册。

热键页显示主绑定成功数量、实际注册组合数量（包含强制触发组合）和失败原因。内部重复绑定会显示对应动作；外部占用可检测，但 Windows 注册接口不提供占用程序名称。

鼠标拖动截图手势默认关闭。在同一页明确开启，录制修饰键并选择 Left（左键）、Middle（中键）或 Right（右键）；关闭后立即停止监听。不要与 PowerToys 等工具使用相同的手势。

默认键只在新配置或相应迁移时补充；已有 data/settings.json 中清空或自定义过的键优先。先到设置 → 热键查看当前绑定，不以记忆中的默认值判断故障。

| 常见默认键 | 功能 |
| --- | --- |
| F1 | 截图复制 |
| Ctrl+F1 | 截图扫码 |
| F3 | 贴剪贴板图片、动图或文字 |
| Ctrl+F3 | 截图并贴图 |
| Ctrl+Shift+F2 | 滚动截图 |
| Ctrl+Q | 收起全部贴图 |
| Alt+Q | 收起光标下贴图 |
| Ctrl+Shift+F3 | 切换光标下贴图置顶 |
| Ctrl+Shift+F4 | 打开贴图管理 |
| Ctrl+Alt+S | 切换跨屏框选 |
| Ctrl+Alt+F5 | 显示主窗口 |
| Ctrl+Alt+Backspace | 框选加入热键排除列表 |

截图标注、剪贴板标注、屏幕批注也有可绑定动作；历史配置常用 Ctrl+Shift+F1、Ctrl+Shift+E、Ctrl+Alt+D，但本包的首次配置不保证全部预绑定。录制、录音、录制面板和停止全部默认为未绑定，避免抢占游戏按键。

## 冲突和排除

系统、其他截图软件、游戏或远程桌面可能先占用某组合。注册失败时改成其他键；全屏应用中可先验证窗口模式。可将应用加入排除列表，避免在它获得焦点时执行指定热键。鼠标手势和强制修饰键按各自设置执行。

录制动作可切换最近的同类型会话；需要同类型多区域时从录制面板新开。Esc 在录制框选时取消选择，正式录制期间不全局抢占 Esc；控制窗获得焦点时 Esc 才停止该会话。

## 执行外部命令

设置 → 执行命令可分别填写程序、参数、工作目录并绑定热键。参数中的带空格路径需加英文双引号；需要 shell 语法时明确指定 powershell.exe 或 bash，而不是把管道符当普通程序参数。

按实际需要选择管理员运行。程序本身提权时，未勾管理员的命令会尝试通过桌面普通令牌启动；无法取得普通令牌时明确报错，不悄悄升权。管理员实际环境仍需结合用户桌面验证。

以保存笔记、归档文件为目的时，先在终端使用同样参数验证，再绑定快捷键。命名模板不是命令模板，不执行任何 shell 表达式。

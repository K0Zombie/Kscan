Kscan 使用手册

开始使用

解压与启动

完整解压便携 ZIP，运行 kscan-gui.exe。不要只复制 exe，旁边的 DLL、原生库和资源都需要保留。自包含 Windows x64 包无需另外安装 .NET；录制另需 FFmpeg。

kscan.exe 是命令行工具，不能用双击闪过的控制台判断它是否启动成功。程序默认无需管理员权限；普通截图、扫码和贴图也不要求提权。

同一用户仅运行一个实例。启动新目录的程序时，如果旧实例仍在托盘，通常只会唤起旧实例。换测试版前先在托盘菜单退出旧程序，再运行新目录中的 exe。关闭主窗口可能只是收进托盘；需要彻底退出时用托盘退出。

便携数据

根目录的 portable 是便携标记。启用时，设置在 data/settings.json，用户主题、命令和贴图库在 data/user/。设置页显示的实际路径最准确。

迁移或备份时保留整个 data/，不要只保存 settings.json；贴图库的图片与 library.json 必须一起保留。录制文件可能另存在 Videos 或用户自选目录，也需单独备份。

移除 portable 标记并重启会改用系统用户配置目录；Windows 通常为 %APPDATA%/kscan/。这不会自动迁移原便携 data。

升级与回退

  1. 先停止录制，等待文件完成保存，再退出托盘程序。
  2. 备份原程序目录、data 和外部录制文件。
  3. 建议先把新包解压到新目录测试。需要沿用设置时，在双方都退出后复制旧 data 到新目录。
  4. 验证通过后再替换使用入口。旧 ZIP 和旧目录可保留用于回退。

若覆盖升级，请覆盖完整程序文件集合而不是仅替换 exe 或某一个 DLL，且保留已有 data。不要同时把不同版本的 Core、Platform 和 GUI 文件混在一起。

main 与录制分支是两套交付。本手册随功能分支包提供；main 0.1.16 中没有录制、命名规则设置页等新增能力。

找到功能

主窗口分为识别、生成、设置。录制放在设置 → 录制；命名和画面时间文字放在设置 → 命名与标注。录制快捷键默认未占用，可按习惯绑定。帮助按钮打开本地浏览器版手册。

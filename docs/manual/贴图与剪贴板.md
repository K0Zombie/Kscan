# 贴图与剪贴板

F3 读取剪贴板并显示贴图。优先识别 SVG，其次读取图片文件项，再读普通位图，最后按文字或 Markdown 渲染。没有内容时不会创建空窗口。

GIF、动画 WebP 文件项优先于静态位图预览，因此录制 GIF 自动复制后可按 F3 直接播放。PNG、JPEG 等文件项也可打开；失效路径和非图片文件跳过。原始文件路径会保留，后续复制可继续使用原文件。

## 贴图操作

拖动窗口移动，滚轮缩放；右键菜单包含置顶、穿透、复制、另存和分组等操作。大图可以放大超过显示器，不会因桌面窗口尺寸限制把图截掉。放大后部分内容位于屏幕外属于正常几何位置，可移动回来。

Ctrl+Shift+F3 切换光标下贴图的置顶状态；Alt+Q 收起光标下贴图，穿透贴图也可用；Ctrl+Q 收起全部。实际绑定可以改动，按键冲突时检查设置和应用排除列表。

## 动画和 SVG

GIF 支持多帧；动画 WebP 的解码帧数可能与文件描述略有不同。当前 APNG 通常只显示首帧。动画解码保持既有保护：单边最多 2048 像素、最多 600 帧、解码后总帧内存不超过 200MiB。超限以首帧静态显示并记录原因，不等于文件损坏。

鼠标停在动图上按住定格键，默认 Shift，暂停当前帧；松开继续。定格时右键可复制当前帧。普通“复制图片”优先复制原动画文件。原文件被删除后不能恢复它的动画内容。

SVG 可由文件、SVG 剪贴板数据或 SVG 文本打开，作为矢量内容栅格化显示。外部资源、脚本和过大内容不予加载。贴出的 SVG 画面不作为可编辑矢量图形处理。

## 文件、位图与文本

截图复制同时提供位图与 PNG 文件项；资源管理器粘贴会得到文件。GIF 自动复制只提供完整文件，不转成单帧位图。目标聊天软件是否将文件作为动图发送，由它的粘贴策略决定。

纯文本默认按 Markdown 贴出。远程图片地址下载需在设置中单独开启，默认关闭；失败时继续按文字显示。程序不会自动提交聊天消息或搜索。

## 图库、备份与删除

未归组临时贴图收起后不自动进库。加入分组后，图片和窗口位置等状态持久化；GIF/WebP 归组保留原文件。可从贴图管理恢复，或把图片放进分组目录让程序扫描。

便携数据在 `data/user/pins/` 和 `data/user/library.json`。组名、组颜色与窗口主题是不同设置。备份要把图片和索引一起保存。

收起窗口不会删除库文件。Delete 是删除操作，首次会提示再次确认；删除分组可选择移入 `_trash` 或连文件删除。不要把收起与删除当成同一动作。

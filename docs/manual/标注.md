# 截图标注与时间文字

截图标注、标注剪贴板、屏幕批注是独立入口，不会改变截图扫码或直接贴图的流程。小选区可进入快速标注，大区域或需要完整编辑时进入独立编辑器。滚动长图在完成裁切后进入独立编辑器。

## 绘图与编辑

| 工具 | 操作 |
| --- | --- |
| 选择 | 点击或框选，Shift 多选，拖动移动，拖端点调整 |
| 矩形 / 椭圆 | 拖动；Shift 约束为正方形 / 圆 |
| 直线 / 箭头 / 尺寸 | 拖动；Shift 锁定 45°，尺寸以图片像素计算 |
| 画笔 / 高亮 | 按住拖动，高亮使用半透明笔迹 |
| 文字 | 点击图片输入；选择后双击可编辑 |
| 序号 | 单击放置，自动递增 |
| 马赛克 | 拖出遮盖区，颗粒可调整 |
| 折线 | 逐点点击，Enter 或双击结束，Esc 取消 |
| 裁剪 | 拖出范围，选中后 Delete 移除裁剪 |
| 聚光 / 放大镜 | 框出突出区域或展示局部放大 |

滚轮缩放，中键平移；方向键微移，Shift+方向键移动 10 像素。修改属性、移动和删除均可撤销。显示比例只影响查看，不会缩小导出像素。

## 文字与时间标注

普通文字可以调整字号、颜色、换行宽度。文字宽度 0 表示自动宽度。输入时 Enter 换行，Ctrl+Enter 确认文字，Esc 取消本次输入；点击画布也会确认文字。

独立编辑器的“插入时间标注”使用设置 → 命名与标注中的文字模板。例如 `{date:yyyy-MM-dd} {time:HH:mm:ss}`。插入的是当时的固定文字，之后可以选择、拖动、改色、删除和撤销，不会每秒变化。

插入位置在图像左上方，便于继续拖动；字号、颜色、透明度来自时间标注设置。录制文字的四角位置与实时开关只用于录制，不会把普通截图变成活动时钟。

## 完成与取消

画布空闲时 Ctrl+Enter 完成并复制；Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做，Delete 删除选中项。正在输入文字时，第一次 Ctrl+Enter 先确认文字。

Esc 优先取消当前绘制、输入或选择；空闲无选中对象时取消整个编辑。使用原图会跳过标注；识别会先完成结果再识别。导出失败会保留编辑内容供重试。

文件命名模板与画面文字分开。改文件名不会给图片增加水印；插入时间文字也不会强制改变文件名。

# 版本与支持范围

本手册对应 Kscan 0.1.17。

## 已包含

- 截图、扫码、条码生成、多显示器与跨屏框选。
- 双向滚动截图、标注、时间文字与贴图。
- 全局热键、鼠标手势、自定义命令、单实例 IPC 与 CLI。
- Windows GIF、MP4、M4A 录制：系统声音、麦克风与混合音源；实时框选；指针尺寸修正；首帧就绪检测。
- 英文文件命名模板、实时预览、条件、JSON 导入导出与扩展接口。
- 本地 Markdown 与 HTML 帮助随发布包提供。

## 平台边界

Windows 10/11 功能完整。Linux 支持识别、生成、截图、滚动截图、标注与部分贴图能力；全局热键、托盘和录制依赖桌面环境，Linux 侧通常由 niri / Sway 等合成器绑定 CLI 完成。

Wayland 下窗口绝对定位、置顶与鼠标穿透取决于合成器是否支持 layer-shell。GNOME 等环境会降级为普通窗口，不保证置顶、定位或穿透。截图默认调用 `grim` + `slurp`，也可以配置为其他外部工具。

## 功能边界

录制使用 Windows gdigrab 目标帧率，未实现逐显示器刷新事件同步；FFmpeg 单独配置，包内不捆绑。录制画面标注是实际桌面图层，重叠录制可能同时捕获到它。

高级编码参数是受限选项入口，不是任意 FFmpeg 命令行。命名扩展是代码集成接口，没有自动 DLL 加载器或任意脚本执行。counter 仅在当前进程内计数，不是持久业务编号。

动画贴图有帧数、尺寸和总内存上限；APNG 多帧支持受解码器限制。滚动拼接需要画面重叠；跨屏录制、高刷新率、多会话、独占全屏、受保护内容、长时混合音频需要结合实际硬件验证。

识别二维码不会绕过目标服务的登录协议；电脑已登录微信也不代表任意应用都允许免手机确认。

## 开发者构建

需要 .NET 10 SDK。仓库内包含 CLI、GUI 与测试项目：

```text
dotnet build Kscan.slnx -c Release
dotnet test  Kscan.slnx -c Release
dotnet publish GUI/Kscan.App.csproj -c Release -r win-x64 --self-contained true
```

`packaging/build.ps1` 会依次构建、测试并生成 Windows 便携包；`packaging/publish-linux.sh` 与 `packaging/arch/` 覆盖 Linux 目录式发布和 Arch 打包。用户数据不纳入分发包。

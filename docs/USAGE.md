# Kscan 0.1.15 使用手册

Kscan 提供二维码/条码识别与生成、截图、标注、屏幕贴图及命令行工具。本手册对应 0.1.15；实际快捷键以「设置 → 全局热键」为准，升级不会覆盖已有配置。

## 1. 解压与启动

Windows x64：解压整个 `kscan-0.1.15-win-x64-portable.zip`，双击 `kscan-gui.exe`。无需另外安装 .NET。请保留旁边所有 DLL 和运行库。

包内文件：

| 文件 | 用途 |
| --- | --- |
| `kscan-gui.exe` | 图形界面、托盘、全局快捷键 |
| `kscan.exe` | 命令行识别、生成、诊断 |
| `portable` | 便携模式标记，请勿随意删除 |
| `portable-defaults.json` | 首次运行使用的默认配置种子 |
| `docs/USAGE.zh.md` | 本手册，`USAGE.md` 内容相同 |
| `docs/examples/` | 可运行示例与说明 |

便携模式的设置保存在程序目录的 `data/settings.json`；用户主题、贴图库等在 `data/user/` 下。迁移时复制整个程序目录，至少保留完整的 `data/`。升级时先退出旧程序，再覆盖程序文件，保留已有 `data/`。

删除 `portable` 标记并重启后，配置改用系统用户目录。Windows 通常为 `%APPDATA%/kscan/`；具体位置以设置页和 `kscan doctor` 为准。

同一用户只运行一个实例。启动另一份副本可能只是唤起原实例，不表示已切换到新目录的版本。核对版本时先从托盘退出旧实例。

## 2. 快捷键：选择需要的截图流程

以下为新便携配置及迁移补充的默认键。设置中可以改键、清空或为同一动作绑定多个键。

| 默认键 | 操作 | 框选完成后 |
| --- | --- | --- |
| `F1` | 截图到剪贴板 | 复制图片 |
| `Ctrl+F1` | 截图并识别 | 直接扫码 |
| `Ctrl+F3` | 截图并贴图 | 直接贴到屏幕 |
| `Ctrl+Shift+F1` | 截图并标注 | 自动进入快速标注，必要时进入独立编辑器 |
| `Ctrl+Shift+F2` | 滚动截图（Windows） | 手动滚动并自动拼接，完成后进入独立标注 |
| `Ctrl+Shift+E` | 标注剪贴板图片 | 打开独立编辑器 |
| `Ctrl+Alt+D` | 屏幕批注 | 抓取当前屏并打开独立编辑器 |
| `F3` | 贴剪贴板图片或 Markdown | 在屏幕显示贴图 |
| `Ctrl+Q` | 收起全部贴图 | 已归组图片保留在库中 |
| `Ctrl+Shift+F3` | 切换光标下贴图的置顶状态 | 无需聚焦贴图 |
| `Ctrl+Shift+F4` | 打开贴图管理 | 浏览分组和图库 |
| `Alt+Q` | 收起光标下贴图 | 可用于穿透贴图 |
| `Ctrl+Alt+S` | 切换跨屏框选 | 开关跨屏捕获 |
| `Ctrl+Alt+F5` | 显示主窗口 | 打开软件界面 |
| `Ctrl+Alt+Backspace` | 框选排除应用 | 将指定应用加入热键排除列表 |

**扫码、直接贴图、截图标注是三条独立流程。** 新增快速标注不会在 Ctrl+F1 或 Ctrl+F3 后插入编辑步骤。

### 框选与多屏

触发截图后拖动选区，Esc 取消。开启窗口/元素识别时可以点击高亮目标直接截取；识别层级及修饰键可在设置中调整。

跨屏框选开启后可以拖过多个显示器。图像按物理像素拼接，不同 DPI 不会改变输出像素比例；显示器之间的空档可设置为透明或黑色。跨屏窗口识别可以单独关闭。显示器布局在框选期间发生变化时，本次操作会取消。

### 滚动截图

按 `Ctrl+Shift+F2`，框选单屏内的可滚动内容，然后把鼠标放回选区内上下滚动。向上发现的新内容接到长图顶部，向下发现的新内容接到底部；在已采集范围内往返不会重复添加。「撤销上一段」按新增顺序撤销，支持顶部和底部的段落。采集目标间隔为 40 毫秒，采集和拼接分开排队处理，匹配支持至少 32 行或选区高度 5% 的重叠（取较大值）。实际采集速度取决于屏幕和页面绘制；完全跳过一屏、没有重叠时无法补回遗漏内容。软件自动拼成长图，选区外的工具栏显示尺寸、段数和缩略预览。

实时大预览默认显示在选区旁边的遮罩空白区，优先左右两侧，按可用空间展开；避开选区及工具栏，遮罩不会压暗预览。空间不足时尝试上下方或其他屏幕，仍放不下则保留工具栏小预览。实时预览随拼接更新，不暂停采集。

点击实时预览或「放大预览」会暂停采集，按原始像素显示当前长图，支持滚动、100%、适应宽度和缩放。关闭后恢复之前的采集状态；原本暂停的仍保持暂停。原图预览中按一次 Esc 只关闭预览，松开后再次按 Esc 可取消采集。预览不改变导出像素。

采集时选区显示蓝色外框，其余区域变暗；工具栏保持可见。按 Esc 或点击「取消 (Esc)」退出，即使焦点在被截图页面、暂停或正在等待完成时也可退出，退出后遮罩立即清除。

点击「完成并调整起止」后，可按原图行号微调开头和结尾，每次 1 行，并预览保留范围；确认后以 100% 原始像素从顶部进入标注。裁切不缩放、不重采样。

完成标注即可复制，也可保存。采集工具栏提供暂停、继续、撤销上一段和取消。撤销会自动暂停，请将页面滚回上一段的位置后再继续。

请避开固定标题栏、悬浮按钮和底部输入框，并给选区外留出工具栏空间。支持 Windows 单屏纵向双向滚动，不自动滚动页面；内容重复、匹配不确定或重叠不足时会提示并保留已采集内容。上限为 100000 像素高或 1.28 亿像素，先达到哪项就停止，仍可完成已有长图；例如选区宽 1920 像素时最多 66666 行。长图越大，内存占用和导出时间也会增加。原有扫码和贴图快捷键不变。

## 3. 快速标注与独立编辑

### 快速标注

按 `Ctrl+Shift+F1`，选定区域后直接在截图原位置编辑。工具栏优先出现在选区下方，空间不足时移到上方。常用绘图工具直接显示，其他工具在「更多」，颜色和尺寸等在「样式」。

以下情况自动进入独立编辑器：

- 选区宽或高超过当前显示器工作区的 85%。
- 选区跨屏、覆盖工作区以外，或拿不到可靠的屏幕位置。
- 选区上下都放不下工具栏，或屏幕可用宽度不足。

快速模式保持原始像素与屏幕位置，不进行画布缩放、平移。需要放大检查、复杂编辑时点「独立编辑」；已有标注和撤销历史一起带过去。

### 独立编辑器

独立编辑器默认**适应窗口**显示完整图片，`100%` 按钮切到一个图像像素对应一个屏幕像素。滚轮以光标为中心缩放，中键或 Ctrl+左键拖动画布。

显示缩放不会压缩原始图片，也不会改变导出尺寸；只有使用裁剪工具才会缩小导出范围。进入独立编辑不代表更换另一套主题：界面跟随软件的深色、浅色、自定义主题，并可实时切换。

### 工具与编辑

| 工具 | 使用方法 |
| --- | --- |
| 选择 | 点击选择；Shift 多选；空白处拖框；拖动移动；两点图形可拖端点调整 |
| 矩形、椭圆 | 拖动绘制，Shift 约束为正方形或圆 |
| 箭头、直线、尺寸 | 拖动绘制，Shift 锁定 45° 方向；尺寸单位为图像像素 |
| 画笔、高亮 | 按住左键绘制，高亮为半透明笔迹 |
| 文字 | 点击图片直接输入，选择模式双击原文可修改 |
| 序号 | 单击放置，自动递增，撤销后编号相应恢复 |
| 马赛克 | 拖动遮盖区域，样式面板调整颗粒大小 |
| 折线 | 单击添加节点，双击或 Enter 结束，Esc 取消 |
| 裁剪 | 拖出导出范围，新裁剪替换旧裁剪；选中后 Delete 移除 |
| 聚光 | 框出突出区域，外部压暗 |
| 放大镜 | 框出区域，在旁边显示 2 倍局部图像 |

选中标注后调整颜色、线宽或文字属性，修改支持撤销。方向键移动 1 像素，Shift+方向键移动 10 像素。一次拖动作为一步撤销。

文字输入时：Enter 换行，Ctrl+Enter 确认文字，Esc 取消本次输入或修改；点击画布也会确认当前文字。右侧或「样式」面板可设置字号与换行宽度，宽度 0 表示自动宽度、不自动折行。

画布空闲时：Ctrl+Enter 完成并复制，Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做，Delete 删除选中项。普通字母、空格和空闲 Enter 不执行 CAD 命令，也不退出。

Esc 优先取消当前绘制或选择，空闲且没有选中对象时取消本次截图。独立编辑器的「使用原图」跳过标注；「识别」会先完成并复制，再识别结果图。

## 4. 主窗口：识别与生成

截图复制同时提供位图和临时 PNG 文件，可粘贴到聊天软件、编辑器及文件管理器。截图 PNG 编码与落盘在后台完成，使用快速无损压缩，不改变原始尺寸、像素和透明度，临时文件可能稍大。文件准备完成后一次性写剪贴板；如果期间你又复制了其他内容，较早的截图不会覆盖新内容。日志记录编码、落盘和剪贴板写入的分段耗时，便于排查偶发变慢。

识别页支持打开图片、粘贴剪贴板图片和截图识别。多个码会分别显示结果。识别失败可尝试让目标更清晰、保留码周围空白，或调整预处理方案。小图放大不会补回已经丢失的细节。

「设置 → 识别 → 截图扫码后自动打开主页面」默认关闭。开启后，截图扫码（默认 Ctrl+F1）完成会显示主窗口和识别页；取消框选不会触发。开关修改后自动保存。

生成页可以选择码制、尺寸、静区、颜色等参数。常见内容包括文本、网址、Wi-Fi、联系人、邮件、电话、短信和地理位置。二维码加 Logo 时应保留足够静区并使用较高纠错级别；以实际扫码验证为准。

## 5. 贴图与贴图库

按 F3 贴出剪贴板图片，或按 Ctrl+F3 框选后直接贴出。图片可拖动、滚轮缩放；Ctrl+滚轮调整透明度；贴图获得焦点后 Q/E 各旋转 90°，Alt+拖动自由旋转。右键菜单提供复制、保存、原始尺寸、镜像、穿透、置顶、分组等操作。

支持 SVG：复制 SVG 源码、SVG 剪贴板图片或资源管理器中的 `.svg` 文件后按 F3，会渲染成透明图片贴出。也可把 `.svg` 文件放入贴图库分组目录，显示缩略图并双击贴出。当前贴图显示为位图，最大边 4096 像素，复制/另存按图片处理；库中的原始 `.svg` 文件保留。支持 viewBox、透明度、渐变及内部引用，外部图片/样式表和脚本暂不支持。

### 收起与删除

- Esc、Alt+Q、收起一组或收起全部属于收起窗口，已入库图片保留。
- 未分组的临时贴图不会永久入库，关闭后不会在重启时恢复。
- 可把分组内的图片拖到「未分组」卡片：已贴出的直接移出分组，尚未贴出的先贴出再移出。原文件归档到 `_trash`，屏幕上保留一张临时贴图。
- 给图片设置分组才会保存到图库。程序重启后加载图库，但不会自动将所有库图贴满桌面。
- 贴图管理中单击选中，双击贴回屏幕；已显示的图片会被提到前面。整组操作使用「贴这组」「收起这组」。
- Windows 上可从管理器拖动缩略图：拖到分组换组；拖到桌面在松手位置贴出（已显示的图片直接移动，不创建副本）；拖入支持文件/图片的聊天框、以图搜索区域或文件夹则复制原文件。外部目标不接收时，松手直接贴图；按 Esc、右键或关闭管理器仍取消，不贴图。动图传原始动图；无原文件的临时静态贴图导出当前显示内容为 PNG。
- 动图移到「未分组」后仍保留归档原文件的引用，再拖回分组时直接移动原文件，保留全部帧。原文件缺失时取消归组，不再静默保存成首帧 PNG。
- 拖入聊天框/搜索区域是否可用取决于目标软件；普通文字搜索框通常不接收图片。程序与目标软件权限不同也可能影响拖放。拖出不会自动按发送或提交搜索。
- Delete 或库图的删除按钮用于彻底删除。首次使用按提示再次确认；之后按已保存的确认策略执行。

分组目录为 `data/user/pins/<分组名>/`，位置、旋转等参数在 `data/user/library.json`。可以往分组目录放入图片，程序会扫描更新；改组名会同步目录名。备份图库请同时备份图片目录与 `library.json`。

删除分组时可选择连图片删除，或将图片移入图库的 `_trash`。移出分组的文件也会移到 `_trash`。不要把“收起窗口”和“删除库文件”混为一谈。

### 动图与限制

动图贴出后可播放；Windows 上光标停在动图上按住定格键（默认 Shift）暂时定格，此时右键直接复制当前帧，松开定格键继续播放，设置中可更改定格键。普通右键菜单的「复制图片」仍复制原动图，菜单不再提供「复制当前帧」。GIF 可多帧播放；动画 WebP 的解码帧数可能少于原文件；当前 APNG 通常只显示首帧。

超大贴图盖住任务栏时，任务栏可能闪烁，这是已知限制。软件保留允许覆盖任务栏的行为。

## 6. 设置、主题和外部命令

设置页可以管理启动、托盘、剪贴板监听、热键排除、跨屏、贴图和标注默认线宽/颜色。标注字体没有独立设置；标注界面沿用软件主题。

主题支持深色、浅色、跟随系统和用户主题。用户主题 JSON 放在 `data/user/themes/`，修改会自动重新加载。界面调整的主题预览要保存到当前主题或另存为主题，才能在下次启动时保留。可直接复制 [示例主题](examples/ocean-theme.json) 到主题目录，再从设置中选择。

贴图管理窗口也随软件主题实时更新背景、字体、选中色、状态色和圆角；分组描边与色块继续使用各组自行选择的标识色。

主题中的 `fontFamily` 是界面字体；标注文字字号在编辑时调整。`mask.style` 的 `none` 表示不铺遮罩，`dim` 表示按 `mask.color` 压暗。主题不会改变截图、标注颜色或导出像素。

外部命令可在设置的「执行命令」中添加并绑定热键。程序与参数分开填写，包含空格的路径要在参数中加引号；需要 shell 管道时明确启动 `powershell.exe` 或 `bash`。普通归档或写笔记示例不需要管理员权限。

详见 [示例目录](examples/README.md)，包括二维码生成/识别自检、剪贴板识别到笔记和文件归档。

## 7. 命令行

Windows 在解压目录打开 PowerShell，使用 `./kscan.exe`。Linux 使用已安装的 `kscan` 或实际可执行文件路径。

### 识别与生成

```powershell
./kscan.exe version
./kscan.exe help
./kscan.exe formats
./kscan.exe gen "https://example.com" -s 480 --ecc H -o code.png
./kscan.exe decode code.png
./kscan.exe decode code.png --json
./kscan.exe decode first.png second.png --verbose
./kscan.exe gen "INV-2026-001" -f CODE_128 --height 120 -o label.png
./kscan.exe gen "https://example.com" --svg -o code.svg
./kscan.exe gen "terminal demo" --ascii
```

`decode` 默认尝试多个码，`--single` 只取单个结果，`--json` 输出结构化信息，`--verbose` 提供诊断信息。图像经 stdin 输入时使用 `decode -`。二进制管道请使用能保持字节的 shell；Windows PowerShell 5.1 的文本管道不适合直接传 PNG。

生成主要参数：`--format/-f` 码制，`--size/-s` 宽度，`--height` 高度，`--margin/-m` 静区，`--ecc L|M|Q|H` 二维码纠错，`--fg/--bg` 颜色，`--output/-o` 输出文件，`--svg` 矢量输出。Logo 使用 `--logo 文件 --logo-scale 0.22 --ecc H`，只支持 PNG。

### 内容模板

```powershell
./kscan.exe build wifi --ssid DemoWiFi --password example-password -o wifi.png
./kscan.exe build vcard --name "示例联系人" --tel +8613800000000 -o contact.png
./kscan.exe build url example.com --svg -o site.svg
./kscan.exe build email --to user@example.com --subject "咨询" -o email.png
./kscan.exe build tel +8613800000000 -o phone.png
./kscan.exe build sms --to +8613800000000 --message "你好" -o sms.png
./kscan.exe build geo 22.3193 114.1694 --label "示例位置" -o location.png
```

不带 `-o` 或 `--ascii` 时，`build` 只打印拼好的内容，方便先检查。

### 截图与诊断

```powershell
./kscan.exe capture --desktop -o desktop.png
./kscan.exe doctor
./kscan.exe toggle
./kscan.exe toggle --capture
```

Windows CLI 没有框选通道，`capture --region` 请改用 GUI 热键。`toggle` 是向已运行 GUI 转交切换/截图命令，不是独立标注命令；无运行实例时退出码为 3。

Linux 的框选依赖外部工具，例如 Wayland 下安装 grim 和 slurp 后：

```bash
kscan capture --region -o shot.png
kscan capture --region --scan
grim -g "$(slurp)" - | kscan decode -
```

CLI 常见退出码：0 成功，1 没识别到码，2 参数、环境或读写错误。批量输入有失败时也要检查退出码和 stderr。

## 8. 排查与备份

| 现象 | 先检查 |
| --- | --- |
| 改版后看起来没变化 | 是否仍运行旧目录的实例，退出托盘后再启动新目录 |
| 快捷键没反应 | 是否被清空、冲突、处于排除应用中；托盘进程是否存在 |
| Windows CLI 框选失败 | Windows 没有 CLI 框选通道，使用 GUI 热键 |
| 快速标注变成独立编辑 | 选区比例、跨屏情况和上下工具栏空间，属于自动回退 |
| 图库重启后没有自动贴图 | 正常；打开贴图管理，双击图库图片贴出 |
| 未分组图关闭后找不到 | 临时贴图没有入库，需先设置分组 |
| 新 DLL 导致启动失败 | 应一起更新 GUI 和所有 Kscan DLL，不要只复制 exe 或一个 DLL |
| 自定义主题没生效 | JSON 是否有效、是否放在当前配置对应的主题目录、id 是否使用保留值 system |

日志通常在 `%APPDATA%/kscan/gui.log`，崩溃信息在同目录的 `crash.log`；便携目录也可能有相关日志。报告问题时注明版本、显示器布局/DPI、触发热键及复现步骤。

便携包是干净程序，源码包是开发快照，两者均不等于个人图库备份。保留个人设置和图库时另行复制 `data/`。交付包旁的 `.sha256` 用于核对下载或复制是否完整：

```powershell
Get-FileHash .\kscan-0.1.15-win-x64-portable.zip -Algorithm SHA256
```

## 9. 从源码构建

源码包包含 `Kscan/`、`pack.ps1` 和交接文档。安装 .NET 10 SDK，在解压目录运行：

```powershell
dotnet build .\Kscan\Kscan.slnx -c Release
dotnet run --project .\Kscan\CLI -- version
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\pack.ps1
```

脚本会发布 Windows x64 自包含便携版、源码 ZIP 及 SHA-256，输出到 `artifacts/`；同名历史交付存在时改用时间戳名称。源码 ZIP 排除构建缓存，包含本手册与示例。更详细的内部设计见 [DESIGN.md](DESIGN.md)。
